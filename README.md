# Doodle Jump Clone (Godot 4)

Простая мобильная игра в стиле Doodle Jump.

## Как запустить

1. Скачай **Godot 4.3** или новее (стандартная версия, не .NET):
   https://godotengine.org/download

2. Распакуй и открой Godot.

3. Нажми **Import** → выбери папку этого проекта → Open.

4. Нажми кнопку Play (▶) сверху.

## Управление

- **Стрелки влево/вправо** или **A / D** — движение
- На телефоне потом добавим наклон или касания

## Что уже есть

- Персонаж с гравитацией и прыжком
- Генерация платформ
- Камера, которая следует вверх
- Счёт очков
- Проигрыш при падении
