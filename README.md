# Doodle Jump Clone — почти готовая мобильная игра

Игра в стиле Doodle Jump на **Godot 4**.

**Репозиторий:** https://github.com/tenttello/doodle-jump-clone

## Что уже есть

- Управление **пальцем** (тач)
- Прыжки, платформы, камера вверх
- Счёт и **рекорд** (сохраняется)
- Несколько **скинов** персонажа
- **Магазин скинов** за монеты
- Монеты за прогресс
- Рост **сложности** с высотой (движущиеся и ломающиеся платформы)
- Меню / Магазин / Игра / Game Over
- Кнопка **Донат** (заготовка под реальные покупки)

## Честно про донаты

Настоящие платежи Google Play / App Store **нельзя** полностью включить только кодом.

Нужно:
1. Аккаунт Google Play Console (разовый взнос) и/или Apple Developer
2. Создать приложение в консоли магазина
3. Добавить in-app products
4. Подключить плагин биллинга в Godot

Сейчас магазин работает на **внутриигровых монетах**.  
Это нормальная база — реальный донат подключается поверх.

## Как запустить на компьютере

1. Скачай Godot 4.3+ (обычная версия, не .NET): https://godotengine.org/download
2. Скачай проект: на странице GitHub → зелёная кнопка **Code** → **Download ZIP**
3. Распакуй
4. Открой Godot → **Import** → выбери папку проекта → Open
5. Нажми **Play** (▶)

## Как поиграть на телефоне (Android)

1. В Godot: **Project → Export → Add… → Android**
2. Установи JDK и Android SDK (Godot покажет подсказки)
3. Собери APK и установи на телефон

## Управление

- Палец **слева** от центра экрана — влево
- Палец **справа** — вправо
- На ПК: A/D или стрелки
