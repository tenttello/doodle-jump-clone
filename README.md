# Doodle Jump Clone — почти готовая мобильная игра

Игра в стиле Doodle Jump на **Godot 4**.

## Что уже есть

- Управление **пальцем** (тач / свайп)
- Прыжки, платформы, камера вверх
- Счёт и рекорд (сохраняется)
- Несколько **скинов персонажей**
- **Магазин скинов**
- Система монет (зарабатываются в игре)
- Рост сложности с высотой
- Экран меню / магазин / игра / game over
- Заготовка под **донат / in-app purchases**

## Важно про донаты

Настоящие платежи (Google Play / App Store) нельзя полностью включить только кодом.

Чтобы донат реально работал, нужно:
1. Создать аккаунт разработчика Google Play (разовый платёж) и/или Apple Developer
2. Создать приложение в консоли
3. Добавить in-app products (например: «Убрать рекламу», «Набор монет», «Премиум скин»)
4. Подключить официальный плагин биллинга в Godot

Сейчас в игре магазин работает на **внутриигровых монетах**.  
Кнопка «Донат» подготовлена — её можно связать с реальными покупками позже.

## Как запустить

1. Скачай Godot 4.3+ (стандартная версия): https://godotengine.org/download
2. Скачай этот проект (Code → Download ZIP)
3. Import в Godot → Play

### На телефоне (Android)
1. В Godot: Project → Export → Android
2. Нужен JDK + Android SDK (Godot подскажет)
3. Собери APK/AAB и установи на телефон

## Управление

- Палец влево/вправо по экрану — движение
- Или наклон (можно добавить позже)
- R / кнопка — рестарт после проигрыша

## Скины

Открываются за монеты в магазине.  
Выбранный скин сохраняется.
